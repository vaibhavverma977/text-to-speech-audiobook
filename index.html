Audio Download Test

Not implemented

The Web Speech API speaks straight to your device’s audio output. It does not return an MP3 file, an audio Blob, or any other downloadable audio object.

  • Browser speech synthesis output is not exposed as a capturable MediaStream, so MediaRecorder cannot record it directly.
  • There is currently no free, offline, browser-only way to turn speechSynthesis output into a real audio file.
  • For that reason this prototype deliberately ships no download button. A button that produced an empty file or a text file renamed to .mp3 would be misleading.

Recording and export will be added only after a browser-compatible approach has been verified. Until then, playback happens live through your device speaker.
